🎨 Full CSS 2.1 & .css File Support

Lynx is configured with comprehensive CSS 2.1 style mappings and dedicated .css document rendering:

  • CSS 2.1 Structural & Typography Rules: Rich terminal colors for h1-h6, em, strong, code, pre, blockquote, table, form, fieldset, and pseudo-classes.
  • Direct .css File Viewer: Open local or web .css files directly in Lynx (e.g. :Lynx style.css or :Lynx https://example.com/style.css) to view formatted CSS code with full styling.

🎓 Master Qutebrowser-style Keyboard Navigation

Key Action Shortcut Description
Navigate Links / Inputs j / k or Up / Down Move focus to previous or next link or form field (Vim keys active).
Follow Link / Submit Form l or Right or Enter Follow focused link or submit active input form.
Go Back h or Left Go back to previous page in history stack.
Open URL Prompt (Qute-style :open) g Open 'Go to URL' prompt (type any web address or domain).
Jump by Link Number 1 - 9 + Enter Jump directly to a specific numbered link on screen.
Scroll Half / Full Page Space / b Scroll down or up one full window page height.
Search Text on Page / then text Search for text in current document (n for next match).
View Document Source \ (backslash) Toggle raw HTML page source mode.
Quit Lynx Window q or Q Exit Lynx session and return to NeoVim buffer.

⚡ NeoVim Lynx Commands Cheatsheet

  • :Lynx [url_or_css] — Toggle or open floating minimal Lynx browser (opens this portal by default).
  • :LynxSplit [url_or_css] — Open Lynx in a vertical window split.
  • :LynxGopher [url] — Quick launch a Gopher URL.
  • :LynxGx or press gx in Normal mode — Open URL or CSS under cursor.
  • :LynxClearCache — Clear offline sandbox cache.
  • :LynxReload [url] — Force refresh document or stylesheet.
  • <leader>bb / <leader>ww — Keymaps to toggle floating Lynx browser instantly.
