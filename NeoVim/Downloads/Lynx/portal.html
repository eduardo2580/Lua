🎓 Master Lynx Keyboard Shortcuts (Chrome-in-Terminal Guide)

Key Action Shortcut Description
Navigate Links Up Arrow / Down Arrow Move focus to previous or next link/input field.
Open Link Right Arrow or Enter Follow the currently focused link or form action.
Go Back Left Arrow Go back to the previous web page in history stack.
Open URL / Address Bar g Open 'Go to URL' prompt (type any address or domain).
Jump by Link Number 1 - 9 + Enter Jump directly to a specific numbered link on screen.
Page Scroll Down Space or PageDown Scroll down one full screen height.
Page Scroll Up b or PageUp Scroll up one full screen height.
Find / Search Page / then type text Search for text string inside current document (n for next).
Bookmarks a (Add) / v (View) Add current page to bookmarks or view bookmark list.
History Stack Backspace or DEL Display document history list.
Options Menu o Open Lynx user preferences and configuration menu.
View Source \ (backslash) Toggle raw HTML page source mode.
Download File d Download targeted link or file to disk.
Quit Lynx q or Q Exit Lynx browser session and return to NeoVim window.

⚡ NeoVim Lynx Commands Cheatsheet

  • :Lynx [url] — Toggle or open floating Lynx browser (opens this portal by default).
  • :LynxSplit [url] — Open Lynx in a vertical window split.
  • :LynxGopher [url] — Quick launch a Gopher URL.
  • :LynxGx or press gx in Normal mode — Open URL or search phrase under cursor.
  • <leader>bb / <leader>ww — Keymaps to toggle floating Lynx browser instantly.
